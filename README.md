# DJ Nelly

Вставил ссылку с YouTube, mp3 упала в папку **DJ Nelly/YouTube**. Больше ничего делать не надо.

- mp3 320 kbps, с обложкой (квадратной) и названием трека в тегах
- папку **DJ Nelly** приложение находит само: в домашней папке, на дисках и флешках.
  Если не нашло, спросит один раз, где она, и запомнит. Папку **YouTube** внутри создаст само.
- можно кидать много ссылок подряд, они встанут в очередь
- ссылка на плейлист скачает весь плейлист, ссылка на видео из плейлиста скачает только это видео
- SoundCloud и другие сайты тоже работают
- если трек уже скачан, напишет «Уже есть в папке»

## Как запустить

1. Нужен Python с [python.org](https://www.python.org/downloads/) (версия 3.10 или новее).
   На Windows при установке поставь галочку **Add python.exe to PATH**.
2. Скачай эту папку: зелёная кнопка **Code → Download ZIP**, распакуй куда угодно.
3. Запусти двойным кликом:
   - **Mac:** `DJ Nelly.command`
   - **Windows:** `DJ Nelly.bat`

Первый запуск займёт минуту-две: приложение само скачает всё нужное (yt-dlp, ffmpeg).
Дальше открывается за пару секунд и при каждом запуске само обновляется, потому что YouTube
постоянно что-то ломает.

### Если Mac не даёт открыть

Mac ругается на файлы из интернета. Один раз сделай так: **Системные настройки → Конфиденциальность
и безопасность**, внизу будет «DJ Nelly.command заблокирован», жми **Всё равно открыть**.
Если Mac спросит доступ к папкам (Документы, Рабочий стол), разреши: так приложение ищет папку DJ Nelly.

## Как пользоваться

Скопировал ссылку → в окошке нажал **Ctrl+V** (на Mac **Cmd+V**) → всё. Можно просто нажать Enter после вставки,
можно правой кнопкой → «Вставить ссылку». Русская раскладка не мешает.

Правой кнопкой по окну: **Открыть папку**, **Сменить папку**. Клик по строке «Папка: …» тоже открывает папку.
